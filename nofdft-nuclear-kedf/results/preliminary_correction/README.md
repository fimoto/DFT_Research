# preliminary_correction: fully reproducible no-path shared fit + diagnostics

The "preliminary correction" of the manuscript is the shared kernel fitted
WITHOUT the selected-path energy-rise rows. Everything here is regenerable by
third parties from the released inputs:

  kernel      : kernels/diagnostics/eg_NP14_shared.dat (+_shift.txt)
                regenerated by  `python3 scripts/kernel_fit.py shared_nopath`
  namelists   : namelists/preliminary/prelim_A80_{ite,diag}_TEMPLATE.nml
                (stage ks_A80_nr250.dat and eg_NP14_shared.dat as kernel.dat;
                 substitute @S2@ / @NMU@ as documented in the templates)

Data (KS-initialized A=80; KS rho_c = 0.1769 fm^-3):

  s2_scan/s2_<s2>_{d,h,s}.dat   8000-step nmu=24 ITE for s2 = 0, 0.2, 0.5,
                                1.0, 2.0 fm^4; central density stays depleted,
                                rho_c = 0.0608-0.0629 (the gradient term does
                                NOT remove the depletion for this correction)
  s2_scan/diag_s2_0.0_{d,h}.dat rearranged diagonalization at s2=0: converged
                                (residual < 1e-8) depleted fixed point,
                                rho_c = 0.0608; the 8000-step ITE endpoint
                                agrees with it to relative L2 2.0e-4
  nmu48_prelim/                 3000-step nmu=48 ITE at s2=0: the depletion
                                persists (rho_c = 0.0626)
  nmu48_released/               8000-step nmu=48 ITE of the RELEASED shared
                                functional (eg_SH14, s2=0) + its nmu=64 energy
                                readout and nmu=48 NLF: rho_c 0.2011->0.1977
                                (1.7%), rrms 4.103->4.092 fm, d_NLF
                                0.0904->0.0936, E^(64) -898.53->-899.03 MeV
                                (quadrature-sensitivity reference of the paper
                                appendix)
  scan_summary.json             machine-readable summary of the above

The failure endpoint that defines the released trial paths is
scripts/path_data/a80_artifact_endpoint.dat (see scripts/make_paths.py).
